## 参数放行门

| 检查 | 放行条件 |
|---|---|
| 电机与电池电压 | 电机允许范围覆盖 1S 锂电满充 4.2V 至使用下限；若材料包电池不是 1S，先停下重新核算驱动板和全部负载。 |
| DRV8833 芯片与板级能力 | 确认完整芯片封装以及该模块在 1S 电压、实际散热条件下的单路连续电流；不能把 5V 条件下的数据直接当作 1S 实际能力。 |
| 工作和启动电流 | 电机带桨工作电流低于已确认的驱动板连续能力；启动峰值在芯片和电源允许的瞬态范围内。只采用卖家/数据手册给出的规格或安全的限流测量，不做堵转测量。 |
| 电池和连接器 | 电池持续放电能力及插头额定值覆盖台架实际负载；一电池带多电机前，先按所有电机的最坏同时工作电流核算。 |
| 电气接口 | 板上 VM、GND、AIN/BIN、STBY 位置与实物丝印一致；Mosaico 3.3V 逻辑兼容性有数据依据；动力电流走独立线束，主控和驱动共地。 |
| 机械状态 | 第一轮测试拆下桨叶并固定电机/驱动板；台架外有可立即拔除的动力断电点。 |

任何一项缺少关键数据时，结论写“待确认”，不接动力电池、不运行电机。DRV8833 手册给出的 0.5A/路（PW）和 1.5A/路（PWP/RTY）是在 VM=5V、25°C 条件下的数据；VM 低于 5V 时输出电流能力下降。必须核实到货封装与板级散热，不能按商品标题放行。

> 请确认本订单“焊好排针”SKU 实际焊接的 DRV8833 完整芯片型号和封装（PW、PWP 或 RTY），单块模块含排针重量、端子丝印定义，以及 VM=3.0–4.2V 时每路连续电流和允许的短时峰值/持续时间。请提供模块 STBY 是否有板载上拉/下拉或其他改动的原理图/说明，并确认当前 SKU 的数据手册。请按实际电机与电池插头提供成品转接线，不需要客户焊接。

## 接线前准备

1. 断开 Mosaico USB 和全部电池；拔下右侧 Interaction 模块，露出 H1；摄像头先取下收好。Interaction 占用 GPIO46/47/11/10/5/38，与六路电机信号冲突。取下三台电机的桨叶。
2. 按到货实物逐个核对驱动板端子、针脚、极性与线束通断。不要仅依商品照片左右定位。
3. 用万用表检查电池输出极性、VM 与 GND 之间无明显短路，并检查所有电机两线没有碰到机架/导电件。
4. 准备有明确电流读数的限流电源或电流表；若使用锂电池，配合按测得负载选定的保险/动力断电线。未知规格的电池不用于首测。
5. 采用项目提供的单通道台架固件：固件明确实际 GPIO、PWM 频率/范围、启动默认低电平、命令超时、E-STOP 行为和目标驱动板通道。当前规划针脚见 [DRV8833 接线说明](README.md) 与 [逐线表](wiring.csv)；首轮只用板 1 的 A 桥，BIN1/BIN2 接本板 GND，BO1/BO2 留空。GPIO/PWM 适配在参数评审后实现并实测。

## 单通道测试顺序

仅在“参数放行门”通过并有专用台架固件后执行。Mosaico 由 USB-C 单独供电；电机由独立、已核实的动力电源供电；两侧 GND 共地。先只接一块 DRV8833 的一个桥和一台电机，其余桥输入按驱动板要求固定到安全低电平。每根信号线按固件版本的接线表逐项核对。

1. 桨叶保持拆除；固定电机、驱动板和线束；确保动力断电点伸手可及。
2. USB 上电，确认 Mosaico 状态为 DISARMED、输出为零；此时仍不接电机动力电源。
3. 接入限流动力电源并设置不高于已核实的安全电压/电流上限；先确认电机静止、驱动板无异常发热或异味。
4. ARM 后只运行一个方向的最低可靠 PWM，持续约 0.5 秒，记录占空比、电压、电流和现象；停到 0/0 并等待完全停止。
5. 再按程序执行反方向的同一短时动作，确认切换前有 0/0 死区；随后 DISARM。
6. 验证 E-STOP、250ms 控制超时、USB/控制线断开和主控重启时输出归零。软件 E-STOP 不等于断开电机电池；测试者仍需使用外部动力断电点。
7. 检查模块和导线温升、插头松动、电源压降及 Mosaico 重启情况。记录通过后再评审另外两个通道。

出现电流超过限值、驱动板/电机快速升温、重启、异响、导线或插头发热、方向不确定、输出不能立即归零时，马上断开电机动力电源，记录当时接线和读数，停止后续测试。**不得用手捏住转轴、压住桨叶或堵转电机测试电流。**
