    01 / ARRIVAL

    拍照与称量Photograph & weigh

    拍 DRV8833、电机、电池、插头和每个气囊。统一用克记录。Photograph the driver, motors, battery, connectors, and each balloon. Record grams.

    现场动作Actions

    先断电；拍正反面与丝印；每件称重并记录单位。Power off first; photograph labels and both sides; weigh every part in grams.

    02 / SCREEN

    把卖家资料填入 JSON，确认电压、电流、封装、插头都有来源。Fill the JSON record and source voltage, current, package, and connectors.

    现场动作Actions

    03 / SOFTWARE

    单路固件Single-channel firmware

    先跑主机测试和模拟器，再按当前设备身份更新。Run host tests and simulator before updating the selected live device.

    现场动作Actions

    先运行主机检查；再启动模拟器；硬件更新只使用实时发现的 Mosaico 身份。Run host checks, then the simulator; use only the live Mosaico identity for hardware updates.

    04 / BENCH

    拆桨台架Propeller-off bench

    Interaction 断电取下，只接一台电机，限流后测启停、换向、急停和温升。Remove Interaction with power off. Test one motor with current limit, no propeller.

    现场动作Actions

    桨叶拆下并固定电机；先接 USB，再接限流动力；每次只动作一台电机。Remove the propeller and secure the motor; connect USB first, then limited motor power; run one motor at a time.

    python scripts/check-arrival.py --record hardware/drv8833/arrival-record.template.json
    05 / MODULAR LIFT

    主囊 + 左右侧囊MAIN + SIDE MODULES

    先把浮力拆成可以单独测量的模块。主囊下方的吊舱放环境气压计，气囊内压和漏气检测另立需求。Split lift into modules that can be measured separately. Put the ambient barometer in the ventilated gondola; internal pressure and leak sensing are separate features.

    • 每个气囊单独称重、测净升力weigh and measure lift per module
    • 再测完整悬挂体，最后做近中性配平measure the full suspended body, then balance near neutral
    • BMP581 给相对高度趋势，不等于离地高度BMP581 gives altitude trend, not ground distance
